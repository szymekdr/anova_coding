Coding groups in one-way ANOVA

The same fit, many parameterisations. I walk through cell-means and effects models, treatment (dummy), sum-to-zero (±1), ±½, Helmert, successive-difference and polynomial codings, and show each one three ways: as algebra, as a matrix, and as geometry, where groups are points in "code space" and the model is a plane passing through them.

Section 1

Two ways to write the model

Running example (simulated): nestling body mass (g) in up to four habitat types. Group \(i = 1,\dots,k\) has \(n_i\) birds, and \(y_{ij}\) is bird \(j\) in group \(i\). Sections 3–4 use the first two habitats, 5–6 the first three, and 7 all four.

Cell-means model

Every group gets its own mean. No intercept, \(k\) parameters, and each parameter is directly a group mean.

\[ y_{ij} = \mu_i + \varepsilon_{ij}, \qquad \varepsilon_{ij} \sim \mathcal N(0,\sigma^2). \]

In matrix form the design matrix is the indicator (one-hot) matrix \(\mathbf D\), with \(D_{\,\cdot,i}=1\) when the observation belongs to group \(i\). For \(k=3\):

\[ \begin{bmatrix} y_{11}\\ \vdots\\ y_{1n_1}\\ y_{21}\\ \vdots\\ y_{2n_2}\\ y_{31}\\ \vdots\\ y_{3n_3}\end{bmatrix} = \underbrace{\begin{bmatrix} 1&0&0\\ \vdots&\vdots&\vdots\\ 1&0&0\\ 0&1&0\\ \vdots&\vdots&\vdots\\ 0&1&0\\ 0&0&1\\ \vdots&\vdots&\vdots\\ 0&0&1\end{bmatrix}}_{\mathbf D\;(N\times 3)} \begin{bmatrix}\mu_1\\ \mu_2\\ \mu_3\end{bmatrix} + \boldsymbol\varepsilon . \]

Effects model

A common mean plus a group-specific deviation. This is how ANOVA is usually written in textbooks:

\[ y_{ij} = \mu + \alpha_i + \varepsilon_{ij}, \qquad \mathbf y = \underbrace{\big[\,\mathbf 1 \;\big|\; \mathbf D\,\big]}_{N\times(k+1)} \begin{bmatrix}\mu\\ \alpha_1\\ \vdots\\ \alpha_k\end{bmatrix} + \boldsymbol\varepsilon. \]

There are \(k+1\) parameters but only \(k\) group means to pin them down. The columns are linearly dependent, because the indicator columns add up to the intercept column, \(\mathbf D\mathbf 1_k = \mathbf 1_N\). So \(\operatorname{rank}[\mathbf 1|\mathbf D]=k\), \(\mathbf X^\top\mathbf X\) is singular, and for any constant \(c\)

\[ (\mu,\;\alpha_1,\dots,\alpha_k)\quad\text{and}\quad(\mu+c,\;\alpha_1-c,\dots,\alpha_k-c) \]

give identical fitted values. In plain terms, the model cannot tell "everything is 2 g heavier" apart from "the baseline is 2 g heavier". This is called non-identifiability or over-parameterisation. Sections 4 and 6 let you drag \(c\) and watch it happen.

The fix is always the same. Drop one degree of freedom by imposing a constraint (for example \(\alpha_1=0\), or \(\sum_i\alpha_i=0\)). In practice, we replace the \(k\) indicator columns with \(k-1\) coded columns. Every coding scheme in this manual is a particular choice of that replacement.

Section 2

The one equation that explains every coding

A coding scheme is a \(k\times(k-1)\) coding matrix \(\mathbf C\). Row \(i\) of \(\mathbf C\), written \(\mathbf c_i^\top\), holds the values the covariates \(x_1,\dots,x_{k-1}\) take for every observation in group \(i\). The design matrix is \(\mathbf X = \mathbf D\,[\mathbf 1\,|\,\mathbf C]\), so the model is

\[ y_{ij} = \beta_0 + \beta_1 x_{1i} + \dots + \beta_{k-1}x_{k-1,i} + \varepsilon_{ij}, \qquad (x_{1i},\dots,x_{k-1,i}) = \mathbf c_i^\top. \]

Stack the \(k\) distinct rows of the design matrix (one per group) into a square matrix \(\mathbf B = [\mathbf 1\,|\,\mathbf C]\). The expected value for group \(i\) is just row \(i\) of \(\mathbf B\) times \(\beta\):

\[ \boxed{\;\mu = \mathbf B\,\beta \quad\Longleftrightarrow\quad \beta = \mathbf B^{-1}\mu\;} \]

Everything follows from this:

  • Coefficients are weighted sums of group means. The weights are the rows of \(\mathbf B^{-1}\), called the hypothesis matrix (also "contrast matrix"; the terms are used loosely). To know what \(\beta_j\) means, read row \(j\) of \(\mathbf B^{-1}\), not column \(j\) of \(\mathbf C\). The two coincide (up to scale) only when the columns of \(\mathbf C\) are centred and mutually orthogonal (Helmert, polynomial). For treatment coding they look nothing alike.
  • Estimates are just sample means pushed through \(\mathbf B^{-1}\). With \(\mathbf N = \operatorname{diag}(n_i)\) and \(\bar{\mathbf y}\) the vector of group sample means, \(\mathbf X^\top\mathbf X = \mathbf B^\top\mathbf N\mathbf B\) and \(\mathbf X^\top\mathbf y = \mathbf B^\top\mathbf N\bar{\mathbf y}\), so \(\hat\beta = \mathbf B^{-1}\mathbf N^{-1}\mathbf B^{-\top}\mathbf B^\top\mathbf N\bar{\mathbf y} = \mathbf B^{-1}\bar{\mathbf y}\). This holds whether the design is balanced or not.
  • Every non-intercept row of \(\mathbf B^{-1}\) is a true contrast (its weights sum to 0). That follows from \(\mathbf B^{-1}\mathbf B=\mathbf I\) and the first column of \(\mathbf B\) being all ones. The intercept row's weights sum to 1.
  • Fit is invariant. Any invertible \(\mathbf B\) spans the same column space as \(\mathbf D\). Fitted values, residuals, \(R^2\) and the omnibus \(F\) test are identical for every coding. Only the questions the individual \(\beta\)s answer change.
  • Sampling covariance: \(\operatorname{Var}(\hat\beta)=\sigma^2\,\mathbf B^{-1}\mathbf N^{-1}\mathbf B^{-\top}\). With balanced data, the slope estimates are uncorrelated exactly when the columns of \(\mathbf C\) are centred and mutually orthogonal.

The geometric picture

Treat \(\mathbf c_i\) as a position. Each group is a point in \((k-1)\)-dimensional code space, and the model is the affine function \(f(\mathbf x)=\beta_0+\beta^\top\mathbf x\) evaluated there. With \(k\) points and \(k\) parameters, \(f\) is the unique plane (hyperplane) through the \(k\) group means. It interpolates them exactly: the one-way model is saturated in the groups. Then:

  • \(\beta_0 = f(\mathbf 0)\) is the plane's height at the origin of code space. If the origin is a group's position, \(\beta_0\) is that group's mean. If the origin lies elsewhere, \(\beta_0=\sum_i w_i\mu_i\), where \(w\) are the barycentric coordinates of the origin relative to the group points (\(\sum w_i=1,\ \sum w_i\mathbf c_i=\mathbf 0\)). These are exactly the first row of \(\mathbf B^{-1}\). Centred codings put the origin at the centroid, so \(\beta_0\) = unweighted mean of group means.
  • \(\beta_j = f(\mathbf e_j)-f(\mathbf 0)\) is the slope along axis \(j\): how much \(f\) changes per unit step in \(x_j\). Its meaning depends on where the groups sit along that axis and how far apart they are, which is why rescaling a code from ±1 to ±½ doubles the coefficient.
Section 3 · k = 2

Two groups: a line through two means

With one coded column \(x\), group 1 sits at \(x=a\) and group 2 at \(x=b\). The model is a straight line through the two group means:

\[ \beta_1 = \frac{\mu_2-\mu_1}{b-a},\qquad \beta_0 = \mu_1 - a\,\beta_1 = \frac{b}{b-a}\,\mu_1 + \frac{-a}{b-a}\,\mu_2 . \]

The intercept is the line's height at \(x=0\), and the slope is the change per one unit of \(x\). Switch schemes and watch the same two means get re-described. The custom option lets you drag \(a\) and \(b\) freely.

Section 4 · k = 2, both indicators

Two indicators and the response: a plane on a hinge

Now keep both indicator columns \(d_1,d_2\) and put the response on the vertical axis. Group 1 lives at \((d_1,d_2)=(1,0)\), group 2 at \((0,1)\). Every observation sits on the line \(d_1+d_2=1\). The effects model \(f(d)=\mu+\alpha_1d_1+\alpha_2d_2\) is a plane over the \((d_1,d_2)\) floor.

The data only constrain the plane along that line. The plane is free to rotate around it like a door on a hinge. Each angle is one value of \(c\) in \((\mu+c,\alpha_i-c)\), and each gives the same fitted values. The intercept \(\mu=f(0,0)\) is the height above the corner where no bird lives. Each constraint picks one angle:

  • \(\mu = 0\) (no intercept): the plane passes through the origin, and \(\alpha_i\) are the cell means.
  • \(\alpha_1=0\) (treatment): \(\mu=\mu_1\), \(\alpha_2=\mu_2-\mu_1\).
  • \(\alpha_1+\alpha_2=0\) (sum-to-zero): \(\mu=(\mu_1+\mu_2)/2\), \(\alpha_i=\mu_i-\mu\).

Section 5 · k = 3

Three groups: a plane through a triangle

With \(k=3\) and two coded columns \((x_1,x_2)\), each group is a point on the floor, and the three points form a triangle. The model \(f(x_1,x_2)=\beta_0+\beta_1x_1+\beta_2x_2\) is the unique plane through the three group means above them. Changing the coding moves and reshapes the triangle. The plane above it changes to match, but its heights at the group positions (the fitted means) never change.

The small map on the right shows where the origin sits relative to the groups. That location fully determines what \(\beta_0\) means.

Code-space map. The origin's barycentric weights with respect to the three group points are the first row of \(\mathbf B^{-1}\), so they give \(\beta_0=\sum w_i\mu_i\).
Section 6 · k = 3, all three indicators

Three indicators: data on a simplex, the intercept off it

Use all three indicators \(d_1,d_2,d_3\) as \(x,y,z\) axes. The groups sit at the unit vectors \((1,0,0),(0,1,0),(0,0,1)\), and every observation lies on the triangle \(d_1+d_2+d_3=1\) (the 2-simplex, shaded). There are now three spatial axes, so the response is drawn as bubble size (area ∝ mass) and colour.

The effects model \(f(\mathbf d)=\mu+\sum\alpha_id_i\) is a linear function of all of 3-D space, but the data only touch the simplex. Values at the vertices (the group means) are fixed, and so is the value at the centroid (the unweighted mean of means). Off the simplex, along the ray from the origin to the centroid, the function depends on \(c\). The bubble at the origin is the intercept, and nothing in the data supports its size. In this picture, a constraint is a rule for choosing it. A cell-means model (no intercept) is just one more such rule: it fixes the origin's value at 0.

Constraint
Axes: indicators \(d_1,d_2,d_3\). Bubble area ∝ \(f\) (mass in g, measured from 0); colour also encodes \(f\). Vertex bubbles = group means (fixed). Grey bubbles along the dashed ray from origin to centroid show \(f\) off the data plane, and these change with \(\mu\).
Section 7 · k = 4

Four groups, three contrasts: a tetrahedron of bubbles

With four groups we need three coded columns, so code space is 3-D. The four groups are vertices of a tetrahedron, and the model is a hyperplane in 4-D, which I can't draw. So the response becomes bubble size again. Each vertex bubble is a group mean (always the same four). The bubble at the origin is \(\beta_0\), and it moves around inside or onto the tetrahedron as the coding changes. The arrow from the origin points along \((\beta_1,\beta_2,\beta_3)\), the direction in code space in which predicted mass rises fastest.

Polynomial coding assumes the levels are ordered and equally spaced. Here, treat habitats 1→4 as a gradient purely for illustration.

Section 8

Pitfalls and software

  1. ±1 coding halves the two-group difference. With \(x\in\{+1,-1\}\) (R's contr.sum), \(\beta_1=(\mu_1-\mu_2)/2\). Groups are 2 units apart, so the slope per unit is half the gap. With ±½, \(\beta_1\) is the full difference. When extracting effect sizes from published coefficients for a meta-analysis, the coding has to be known. A factor of 2, or a flipped sign (which group got +1), goes straight into the effect size.
  2. "Grand mean" is ambiguous when data are unbalanced. Centred codings give \(\beta_0=\frac1k\sum_i\mu_i\), the unweighted mean of group means. The overall sample mean \(\bar y_{\cdot\cdot}=\sum_i n_i\bar y_i/N\) is a different number. Flip the sample-size toggle at the top and compare them in Sections 5–7.
  3. Centred ≠ orthogonal. Sum and successive-difference codings are centred (so \(\beta_0\) is the mean of means), but their columns are not orthogonal, so their slope estimates are correlated even in a balanced design. Helmert and polynomial codings are both centred and orthogonal. The algebra panels report \(\operatorname{corr}(\hat\beta_j,\hat\beta_l)\).
  4. The coding matrix is not the hypothesis. For treatment coding, column 1 of \(\mathbf C\) is \((0,1,0)^\top\), yet \(\beta_1\) tests \(\mu_2-\mu_1\). Design from the hypothesis side: write down the rows of \(\mathbf B^{-1}\) you want, then invert. The hypr R package (Rabe et al. 2020) and HypothesisCoding in Julia's StatsModels.jl do exactly that.
  5. With interactions, coding changes what "main effect" means. Under treatment coding, the main-effect coefficient of A in a model with A×B is the effect of A at the reference level of B. Under centred codings, it is the effect averaged over B's levels. This is also why Type III sums of squares are only meaningful with sum-to-zero-type contrasts.
  6. Polynomial contrasts (R's default for ordered factors) are scaled to unit length. \(\beta_1\) is not "g per level", and they only make sense for ordered, roughly equally spaced levels.

Setting codings in software

## R
contrasts(f) <- contr.treatment(3)      # default for unordered factors (dummy, ref = level 1)
contrasts(f) <- contr.sum(3)            # +1/0/-1, sum-to-zero; last level gets -1
contrasts(f) <- contr.sum(2) / 2        # two groups: +/- 1/2 -> slope = full difference
contrasts(f) <- contr.helmert(3)
contrasts(f) <- MASS::contr.sdif(3)     # successive differences
contrasts(f) <- contr.poly(3)           # default for ordered factors
solve(cbind(1, contrasts(f)))           # hypothesis matrix B^{-1}: what each beta means
lm(y ~ 0 + f)                           # cell-means model

## Julia (StatsModels.jl)
fit(LinearModel, @formula(y ~ f), df;
    contrasts = Dict(:f => EffectsCoding()))   # DummyCoding, HelmertCoding, SeqDiffCoding, HypothesisCoding
